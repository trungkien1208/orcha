**Install or update**: one line

macOS (Apple Silicon or Intel), in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.sh | sh
```

Windows (x64), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.ps1 | iex
```

Already on 0.1.2 or later? `orcha update` does it.

Quitting orcha leaves your agents running in the background, so the new version takes over only after a switch. To switch without stopping your agents:

```sh
orcha server live-handoff --import-exe ~/.local/bin/orcha
```

Then open orcha again.

**New in 0.14.0**

- **See how every agent is doing at a glance**: the sidebar now shows each project's panes as a little tree. Under every agent: its model and the git branch it is working on (with commits to push ↑, to pull ↓ and files changed ±), then how full its context is and how much memory it holds. Green means fine, yellow means worth a look, red means too much.
- **Know who has been waiting**: next to each agent's state, how long it has been sitting there (`idle 12m`, `needs you 5m`).
- **Busy projects open by themselves**: a project with an agent working or waiting for you unfolds on its own. Fold it by hand and it stays folded.
- **A friendlier bottom bar**: one colored card for the open pane (🙂 fine, 😐 worth a look, 😵 trouble, with the number that is the problem) and one for how much RAM orcha uses in total.
- **Tidier sidebar**: bigger fold arrows, no dot in front of projects without an icon, and the open pane marked by a yellow branch instead of extra bars.
