**Install or update**: one line

macOS (Apple Silicon or Intel), in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.sh | sh
```

Windows (x64), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.ps1 | iex
```

Already on 0.1.2 or later? `orcha update` does it.

Quitting orcha leaves your agents running in the background, so the new version takes over only after a switch. To switch without stopping your agents:

```sh
orcha server live-handoff --import-exe ~/.local/bin/orcha
```

Then open orcha again.

**New in 0.13.0**

- **Start the next agent from + NEW**: choose an account with its fuel, open a shell, or add another project. Available Orcha shortcuts also appear in COMMANDS and Keybinds.
- **Read the sidebar at a glance**: every agent says what it is doing on its own row: running, needs you, done or idle. Yellow is running, red needs you, green is done, grey is resting. The pane you are in gets a bar, the open project a yellow edge, and quiet projects stay quiet.
- **Follow fuel and hand-offs**: low-fuel agents carry a sidebar mark when their account is known. A hand-off says when it is running, then links the old pane to the pane where the chat continues.
- **The branch follows you**: switch projects and the branch under the name changes right away.
- **Drag projects to reorder** works again.
- **No surprise typing**: the "running low" offer waits in a notice instead of grabbing your keyboard. COMMIT and PR only talk to an agent that is waiting for you, never a plain shell. Esc steps back one level in account popups.
- **Account switches you can trust**: switching a Claude account writes down who owns which sign-in before moving it, and puts things back if the move fails, so a failed switch does not relabel another account's sign-in. Progress stays on screen until a switch or hand-off is done, and failures say what went wrong.
- **Honest errors**: a network hiccup no longer looks like being signed out of Cursor. Uninstall and stopping Easy Job tell you when something did not work.
- **Safer saves**: settings, accounts, CLAUDE.md and AGENTS.md are saved in one go, so a crash or a power cut can't leave them half written. A broken file is left alone instead of being overwritten.
- **Smoother settings and popups**: reloading the settings page keeps working, Escape puts a field back the way it was, list popups scroll to the row you picked, and changing sidebar width in settings takes effect after a mouse drag.
- **Lighter in the background**: every account's fuel is checked at the same time, Codex usage is read from the end of its logs, the Keychain is asked less often, tab bar commands only run while a window shows them, panes are drawn with less work, and when many agents stream at once their status reaches the window in small batches instead of one by one.
- **Checked updates**: `orcha update` runs the selected release’s own installer after verifying its checksum. Both installers verify the downloaded app package too; a failed macOS replacement keeps the current app.
- **Private hand-off notes**: saving a hand-off locks its folder and older Orcha notes to your user, and removes Orcha notes older than two weeks.
- **Plugin checks finish**: a Git helper left behind by an update check can no longer hold its output open forever.
