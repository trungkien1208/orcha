**Install or update**: one line, no questions

macOS (Apple Silicon or Intel), in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.sh | sh
```

Windows (x64), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.ps1 | iex
```

Already on 0.1.2 or later? `orcha update` does it. If orcha then says `config.toml has unknown keys`, the background server is still the old one: `orcha server live-handoff --import-exe ~/.local/bin/orcha` moves it to the new version and every agent keeps running.

**New in 0.9.10 (beta): small fixes, smoother ride**
- **No more flicker under the accounts window**: agents that keep typing no longer draw over it while it is open. The same goes for Commands and every other orcha window.
- **The sidebar follows your branch**: switch branches and the project's `git · branch` line catches up within a second or two.
- **Fuel remembers**: an agent that sits idle keeps showing its last fuel instead of an empty gauge, and a window that reset in the meantime shows full again.
- **Windows install works again** on the PowerShell that ships with Windows. It used to say no release had the Windows zip.
