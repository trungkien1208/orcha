**Install or update**: one line, no questions

macOS (Apple Silicon or Intel), in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.sh | sh
```

Windows (x64), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.ps1 | iex
```

Already on 0.1.2 or later? `orcha update` does it. If orcha then says `config.toml has unknown keys`, the background server is still the old one: `orcha server live-handoff --import-exe ~/.local/bin/orcha` moves it to the new version and every agent keeps running.

**New in 0.9.12 (beta): know where every agent works**
- **See which worktree each agent is in**: the WORKTREES list puts your current checkout on a green band and shows the agents working in every checkout, in their status colors. Even folded, the title tells you how many checkouts have agents in them.
- **Fold BRANCH and CHANGES**: click their titles to shrink them to one line. A folded BRANCH still shows the branch name and whether it is pushed.
