**Install or update**: one line

macOS (Apple Silicon or Intel), in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.sh | sh
```

Windows (x64), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.ps1 | iex
```

Already on 0.1.2 or later? `orcha update` does it.

Quitting orcha leaves your agents running in the background, so the new version takes over only after a switch. To switch without stopping your agents:

```sh
orcha server live-handoff --import-exe ~/.local/bin/orcha
```

Then open orcha again.

**New in 0.14.1**

- **Closing the last pane keeps the project**: orcha opens a fresh shell in the project folder instead of asking to close the whole project. To remove a project, close the project itself.
- **Chat names and models come back after a restart**: an agent that resumes its chat shows the chat's topic and its model again right away, instead of a plain "Claude".
- **Folder access on macOS**: when macOS stops orcha from reading a project in Desktop, Documents or Downloads (this can happen after an update), orcha says so and opens Full Disk Access for you. Shells there failed before with errors like "current working directory must be readable".
- **One download**: the extras (themes, logo font, account and hand-off scripts) now come with each release, checked like the app. Installing no longer needs git.
