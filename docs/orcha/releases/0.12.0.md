**Install or update**: one line

macOS (Apple Silicon or Intel), in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.sh | sh
```

Windows (x64), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.ps1 | iex
```

Already on 0.1.2 or later? `orcha update` does it.

Quitting orcha leaves your agents running in the background, so the new version takes over only after a switch. To switch without stopping your agents:

```sh
orcha server live-handoff --import-exe ~/.local/bin/orcha
```

Then open orcha again.

**New in 0.12.0**
- **Settings in your browser**: click `⚙ settings` in the header (or run `orcha settings`). Every setting on one page, grouped by what you want to do, in orcha's own look and your theme's colors. Press `/` to search, and undo any change from the little note that pops up. A dot shows what you changed, and ↺ puts it back.
- **Your accounts in one place**: see how much each account has left, sign in again, add a Claude account, pick the one new agents start on, or check fuel right now.
- **Before an account runs dry**: three steps you set yourself. Orcha can offer to have the agent write a checklist of what is done and what is next, then ask where to continue, and if you want, move the chat on by itself. Orcha asks before typing anything into an agent.
- **Working rules for your projects**: when you add a project, orcha offers a few rules for its CLAUDE.md, like "plan in slices first" or "verify before saying done". You see the change before anything is written. Popular skills (Superpowers, Ponytail, Grill me and more) install from the same page.
- **What keeps running**: `orcha status` and COMMANDS › Running in background list the server, every agent and its state, and plugin servers, with Go to and Stop.
- **Easy Job**: the `● office` chip lights up again when the office runs, and `orcha office status` and `orcha office stop` join the other office commands.
