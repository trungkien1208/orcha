**Install or update**: one line

macOS (Apple Silicon or Intel), in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.sh | sh
```

Windows (x64), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.ps1 | iex
```

Already on 0.1.2 or later? `orcha update` does it. Coming from 0.9.12? Everything new in 0.10.0 is in here too.

**New in 0.11.0: Easy Job, a pixel-art office for your agents**
- **Add it in one go**: the installer asks once whether you want Easy Job (the answer is no unless you say yes). Said no? Orcha offers it once, and `orcha office install` adds it any time.
- **`orcha office`** opens it. `orcha office update` gets the newest one, `orcha office remove` takes it out (it asks first and keeps your Easy Job data unless you say otherwise).
- **Easy Job updates without waiting for Orcha**: once a day Orcha checks whether a plugin you added from GitHub has a new version. You see "Easy Job 0.2.0 is out · Update" once, COMMANDS keeps an Update row, and Easy Job shows its own Update button. Updating restarts it, so the page comes back on the new version.
- **`orcha update` brings your plugins along**, one line per plugin.
- **Prefer no questions?** Settings, look, "plugin updates": automatic.
- Nothing is downloaded, installed or started without a yes, and Orcha still sends nothing about you anywhere.

<summary>For app and plugin authors (socket protocol 24, unchanged)</summary>

New methods: `plugin.updates {refresh?}` returns each GitHub plugin's current and latest version, whether it runs on this Orcha (`compatible`, `needs_herdr_version`) and its source and ref, from the daily check (no network on call). `plugin.update {id}` installs the newer version and restarts the plugin's running panes, returning `plugin_updated` or `plugin_update_failed` with the end of the build log.

New event: `plugin.updates_changed`. New feature: `plugin.updates`.

`min_herdr_version` is compared with the Herdr core version, not the Orcha release: `orcha --version` prints both (`orcha 0.11.0 (herdr 0.9.5)`). Name the Herdr version; `0.9.0` works on every Orcha since 0.9.

New CLI: `orcha office [install|update|remove]`; `install.sh` takes `--office` or `--no-office`; `[orcha] update_plugins = true` updates plugins without asking.
