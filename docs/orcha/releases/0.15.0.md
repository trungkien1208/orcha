**Install or update**: one line

macOS (Apple Silicon or Intel), in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.sh | sh
```

Windows (x64), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.ps1 | iex
```

Already on 0.1.2 or later? `orcha update` does it.

Quitting orcha leaves your agents running in the background, so the new version takes over only after a switch. To switch without stopping your agents:

```sh
orcha server live-handoff --import-exe ~/.local/bin/orcha
```

Then open orcha again.

**New in 0.15.0**

- **Fuel without the Keychain**: when Claude can't save its sign-in in the macOS Keychain (it is locked, the login keychain broke after a password change, or the Mac is managed), it keeps it in `.credentials.json` instead. FUEL now reads it there too, instead of asking you to sign in. Switching accounts still needs the Keychain; [Orcherd](https://github.com/trungkien1208/orcherd)'s ACCOUNTS says how to fix it in one click.
- **Accounts stop asking to sign in again**: fuel reads each account's most recently refreshed sign-in, and the copy orcha keeps follows it. An access token that ran out but can renew itself shows as idle, not "sign in".
- **A new sign-in reaches fuel and your chats**: signing in no longer leaves fuel saying the sign-in expired, and signing in one account no longer overwrites another's.
- **Two more skills**: Settings › Projects offers ADHD (answers lead with the next step) and caveman (short answers, fewer tokens).
- **More settings on the settings page**: follow the terminal's light and dark, ask before closing a project, and the app each file type opens with on Ctrl+click.
- **Cmd+, opens the settings page**, not the old terminal menu (still there as `orcha menu`).
