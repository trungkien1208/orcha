**Install or update**: one line, no questions

macOS (Apple Silicon or Intel), in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.sh | sh
```

Windows (x64), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.ps1 | iex
```

Already on 0.1.2 or later? `orcha update` does it.

**New in 1.0**
- **Commands**: every action in one search. Click `⌕ commands` in the header or press the prefix key, then `:`.
- **Fuel, accounts and hand-off built in**: no Python needed, and they work on Windows too. Fuel gauges, switching accounts mid-chat, sign in, add an account and NEW all run inside orcha.
- **Hand off that works**: the new agent gets the goal, the latest request, the files the old agent changed, recent commits, and the old agent's screen when its chat file can't be read.
- **Make it yours**: settings are redrawn in orcha's look, with a new `look` tab: accent color, which side the sidebar takes, its width, the right panel, where FUEL and PROCESS sit, pane colors and agent logos, with a sketch that shows the result before you pick.
- **An icon per project**: right-click a project, or use Commands, and pick an emoji for the sidebar.
- **Accounts you can tidy**: refresh every account's fuel with `r`, remove one with `d` (its sign-in and chats stay).
- **Light themes you can read**: status words, gauges and change markers now have enough contrast on light paper.
- **Ask every agent here**: one prompt goes to every agent in the project.
- **New worktree from NEW**: start a branch in its own folder for an agent beside the current one.
- **"N needs you" in the header**: click it to go to the waiting agent.
- **Desktop notifications on by default** when an agent needs you or finishes in the background.
- **Imports without duplicates**: a folder known to Orca, VS Code, Cursor and JetBrains shows up once, and projects that are already open are skipped.
- **Lighter git panel**: it reads less often while nothing changes, and history only when the branch moves.
- **Intel Macs** get a ready-made build too.

**Fixed**
- Signing in to an account of the default Claude folder no longer swaps it with the active account.
- A running server from an older orcha no longer reports orcha's newer settings as unknown keys.
- Commit and pull request buttons work on Windows.
- A new release is published only once every package is attached.
