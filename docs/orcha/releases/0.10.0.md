**Install or update**: one line, no questions

macOS (Apple Silicon or Intel), in Terminal:

```sh
curl -fsSL https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.sh | sh
```

Windows (x64), in PowerShell:

```powershell
irm https://raw.githubusercontent.com/trungkien1208/orcha/HEAD/install.ps1 | iex
```

Already on 0.1.2 or later? `orcha update` does it. This release changes how orcha's parts talk to each other, so quit orcha and open it again afterwards (your agents resume where they were).

**Then update the agent hooks once**:

```sh
orcha integrations install --outdated
```

Codex asks you to look at its hooks the next time it starts: type `/hooks` and trust them.

**New in 0.10.0 (beta): orcha talks to other apps**
- **Easy Job and other apps stay in sync live**: they see every agent's status, model, what it is doing right now and its full chat, the moment it changes, without polling or reading files.
- **Two ways to move a Claude chat to another account**: keep Claude running and only swap the sign-in (other Claude chats on that sign-in move too), or restart Claude on the new account and pick the same chat back up (only this one moves). Orcha asks which when you switch.
- **Accounts and fuel for apps too**: list accounts with their fuel, switch an agent's account, sign in, add, rename or remove accounts from outside orcha. Nothing secret ever leaves orcha.
- **Change model, effort and speed in one go**: for Claude and Codex, from orcha or any app. A busy agent gets the change as soon as it is free.
- **Questions as buttons**: when an agent asks something, apps see the question and its choices and can answer it.
- **New agents never steal your screen**: starting an agent, a sign-in or a hand-off from an app opens in the background.
- **Plugins in COMMANDS**: actions of linked plugins show up in the command palette. If Easy Job is on your Mac, orcha offers to add it (only if you say yes) and can start it quietly with orcha.
- **PROCESS knows what each agent is doing**: THINK while it reads or reasons, CODE while it edits, TEST while it runs tests or checks, and agents waiting for you come first.
- **Open as many projects as you like in the sidebar**: a project stays open when you switch to another, orcha remembers which are open, and COMMANDS can open or fold them all.
- **Control running plugins**: COMMANDS can open a plugin's page in your browser, restart it or stop it.
- **The version is in the header**, so you always know which orcha is running.
- **Cursor's "trust this folder?" now shows as waiting for you**, like Claude's.
- **Prompts that really send**: sending a prompt right after a trust question no longer leaves it sitting in the input.
- **Snappier**: apps get answers in about a millisecond instead of a tenth of a second.

<summary>For app and plugin authors (socket protocol 24)</summary>

Everything is optional and listed in `server.capabilities`; older clients keep working. Full reference: the Socket API page, section "Sync API".

New methods
- `server.capabilities`, `server.multiplex`
- `session.snapshot { since, epoch }` returns a `session_delta`
- `agent.models`, `agent.configure`, `agent.mark_seen`, `agent.question`, `agent.answer`, `agent.handoff`, `agent.transcript.subscribe`
- `agent.start` with `workspace_id`, `account_id`, `prompt`, `model`, `effort`, `fast`
- `accounts.list`, `accounts.plan`, `accounts.switch`, `accounts.login`, `accounts.add`, `accounts.remove`, `accounts.rename`, `accounts.set_default`, `accounts.env`
- `plugin.run_action`, `plugin.autostart.set`, `plugin.autostart.list`
- `pane.report_agent_model`, `pane.report_agent_stage`
- `agent.read` / `pane.read` with `source: "scrollback"`

New events
- `session.changed`, `pane.agent_model_changed`, `accounts.changed`, `agent.transcript`
- `pane.agent_status_changed` for every pane (no `pane_id`), with `state_change_seq`, `session_version`, `stage` and `tool`

New fields
- agent records: `model`, `effort`, `fast`, `stage`, `tool`, `seen_seq`; `agent_session.id` and `agent_session.transcript_path`
- full snapshots: `session_version` and `session_epoch`

Features: `events.subscribe.agent_status_all_panes`, `events.subscribe.ordered`, `pane.agent_status_changed.order_keys`, `session.snapshot.since`, `session.snapshot.result_version`, `agent_session.transcript_path`, `agent.model_state`, `agent.model_state.observed`, `pane.agent_model_changed.all_sources`, `agent.stage`, `agent.seen_seq`, `agent.prompt.confirmed`, `agent.start.workspace`, `read.source.scrollback`.

CLI: `orcha api call METHOD [PARAMS_JSON]` sends any method; `orcha plugin link|unlink|list` manage `herdr-plugin.toml` plugins; `orcha integrations install --outdated`; `orcha status` shows plugins.

Hooks: Claude v12, Codex v11 and Cursor v3 report the session id, transcript file and model at session start.
